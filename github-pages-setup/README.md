# PromptPilot - App Ads Authorization

This repository hosts the app-ads.txt file for PromptPilot iOS app to authorize Google AdMob for ad serving.

## 🎯 Purpose

The `app-ads.txt` file is required by:
- **Google AdMob** for ad serving authorization
- **Apple App Store** for app verification
- **IAB Standards** for programmatic advertising transparency
